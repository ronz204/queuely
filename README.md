#### Queuely | Academic Project

Simulador de colas de pedidos e-commerce durante un pico de demanda (tipo Black Friday), aplicando cálculo integral para modelar, analizar y visualizar el comportamiento de la cola. Es una single-page app sin backend: todo el cálculo corre en el navegador.

## Requisitos

- [Bun](https://bun.sh)

## Levantar el proyecto

```bash
cd projects/queuely-client
bun install
bun run dev
```

Esto abre el dev server en `http://localhost:5173`.

## Otros comandos

```bash
bun run build     # type-check + build de producción
bun run preview   # sirve el build de producción localmente
```
